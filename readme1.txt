============================================
  开源音乐 (Liquid Music) 软件介绍
============================================

【软件名称】开源音乐 / Liquid Music

【软件版本】v1.0

【软件类型】音乐播放与识别应用（Windows 桌面版 + Android 移动版）

============================================
一、软件简介
============================================
开源音乐是一款采用液态玻璃（Liquid Glass）设计风格的音乐应用，
支持多平台音乐搜索、在线播放、听歌识曲等功能。
后端基于 Node.js 零依赖实现，前端采用原生 HTML/CSS/JS，
界面仿 iOS 27 液态玻璃质感，视觉效果精致流畅。

============================================
二、核心功能
============================================

1. 多平台音乐搜索与播放
   - 集成网易云音乐、酷狗音乐、QQ 音乐三大平台
   - 搜索结果跨平台交织排序，不按平台分组
   - 自动检测可播放源，非网易源获取失败时自动回退网易
   - 支持歌曲平台标签显示（红=网易，蓝=酷狗，橙=QQ）

2. 听歌识曲（哼唱识别）
   - 基于 ACRCloud 识别引擎
   - 支持麦克风实时录音识别
   - 支持本地音频文件上传识别（mp3/wav/m4a）
   - 大文件分块处理，自动 base64 编码上传
   - 多种关闭方式：取消按钮、右上角×、遮罩点击、ESC 键

3. 榜单与歌单
   - 三平台榜单数据并行获取，交织合并展示
   - 支持热歌榜、新歌榜、飙升榜、原创榜
   - 精选歌单推荐

4. 播放器功能
   - 歌词同步显示（支持翻译歌词）
   - 播放进度控制、上一首/下一首
   - 播放模式切换（顺序/随机/单曲循环）
   - 收藏功能
   - 迷你播放器（液态玻璃浮动条）

5. 液态玻璃实时调节
   - 玻璃模糊度、饱和度、透明度、高光强度可调
   - 主色调 hue 滑块（0-360 色相调节）
   - 界面密度（紧凑/标准/宽松）
   - 设置自动持久化到 localStorage

6. 背景主题
   - 6 套内置渐变主题（极光、深海、日落、森林、樱花、夜色）
   - 纯色背景模式（自定义颜色选择器）
   - 动态色块动画切换

============================================
三、特色功能
============================================

1. 解锁系统
   - 输入解锁码可激活 VIP 金色主题 / 管理员权限
   - 解锁码支持任意顺序输入，回车确认
   - 管理员可输入 0806 关闭防逆向保护

2. 防逆向保护
   - 定时 debugger 检测（每 4 秒）
   - 检测到调试器时清空控制台
   - 录音期间自动跳过检测，避免影响识曲
   - 管理员可关闭此功能

3. 管理后台
   - 服务器运行状态监控
   - 请求统计（总量、API、识别次数）
   - 识别历史记录
   - ACRCloud / 讯飞凭证配置

============================================
四、运行环境
============================================

【Windows 版】
- 系统：Windows 7 及以上（64 位）
- 无需安装任何依赖，双击 LiquidMusic.exe 即可运行
- 自带 Node.js 运行时，无需额外配置

【Android 版】
- 系统：Android 7.0 及以上
- 需授予麦克风权限（听歌识曲功能）
- 直接安装 APK 即可使用

============================================
五、使用方法
============================================

【Windows 版】
1. 双击 LiquidMusic.exe
2. 软件自动解压到 %LOCALAPPDATA%\LiquidMusic
3. 自动启动本地服务器（端口 3000）并打开浏览器
4. 在浏览器中使用全部功能
5. 关闭弹出的命令行窗口即可停止服务器

【Android 版】
1. 将 APK 文件传输到手机
2. 允许"未知来源"安装
3. 安装后打开应用即可使用
4. 听歌识曲需授予麦克风权限

============================================
六、技术特性
============================================

- 后端：Node.js 零依赖（仅用内置模块 http/https/crypto/fs）
- 前端：原生 HTML5 + CSS3 + JavaScript（无框架）
- 桌面打包：iexpress SFX 自解压
- 移动打包：Capacitor + Android WebView
- 缓存策略：Service Worker 网络优先
- 签名算法：HMAC-SHA1（ACRCloud 识曲）
- 音频处理：Web Audio API + MediaRecorder

============================================
七、文件说明
============================================

开源音乐-debug.apk    Android 调试版安装包

============================================
八、注意事项
============================================

1. 听歌识曲需联网，ACRCloud 凭证可在管理后台配置
2. 部分歌曲因版权限制可能无法播放，会自动尝试其他平台源
3. Service Worker 在开发模式下使用网络优先策略
4. 如遇界面更新未生效，请清除浏览器缓存或强刷页面
5. 关闭命令行窗口即停止 Windows 版服务器
